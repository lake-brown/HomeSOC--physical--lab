# Documentation

This directory contains technical documentation for the Windows Server Active Directory lab.

## Documentation Files

- `architecture.md` – Lab architecture and network design.
- `installation.md` – Windows Server installation and initial configuration.
- `active-directory-configuration.md` – AD DS installation and Domain Controller configuration.
- `powershell-automation.md` – PowerShell automation procedures.
- `group-policy-security.md` – Group Policy and security configurations.

Documentation will include implementation steps, verification procedures, and screenshots as the lab progresses.
