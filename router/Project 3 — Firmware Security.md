# Project 3 — Firmware Security

**Status:** Complete

## Objective

Review the Firewall Router firmware, apply the available firmware update, and verify that the router continued operating correctly after the update.

---

## Security Objective

Keeping network infrastructure firmware current helps ensure that available vendor security fixes and reliability improvements are applied.

The update process was performed as part of the HomeSOC-Lab router security baseline.

---

## Procedure

### 1. Review Current Firmware

The router administration interface was accessed and the installed firmware version was reviewed.

### 2. Check for Updates

The router's firmware update functionality was used to determine whether a newer firmware version was available.

### 3. Apply Update

The available firmware update was applied through the router's management interface.

### 4. Post-Update Verification

Following the update, the following functionality was checked:

- Router accessibility
- Wireless connectivity
- Lab network connectivity
- Internet connectivity
- Firewall functionality
- NAT functionality

---

## Validation

After the firmware update:

- Firewall Router remained accessible
- Lab wireless remained operational
- Lab systems maintained network connectivity
- Internet access remained available
- Firewall configuration remained operational
- NAT remained operational

No sensitive firmware version information is included in this repository.

---

## Security Considerations

This repository does not include:

- Router credentials
- Configuration archives
- Private network addressing
- Sensitive device identifiers
- Authentication information

---

## Result

The Firewall Router firmware was reviewed and updated, followed by functional verification of the lab network.

**Project Status:** ✅ Complete
