# Project 2 — System Updates & Patch Management

## Objective

Ensure the Raspberry Pi Ubuntu Server is running current system packages and security updates.

## Actions Performed

- Refreshed Ubuntu package repositories
- Reviewed available package updates
- Installed available system updates
- Upgraded installed packages
- Rebooted the system after updates
- Verified system availability after reboot

## Validation

- Package updates: Complete
- Remaining upgrades: None
- System services: Verified
- System availability after reboot: Verified

## Security Benefit

Keeping system packages current reduces exposure to known vulnerabilities and ensures the server receives available security fixes.

Complete
