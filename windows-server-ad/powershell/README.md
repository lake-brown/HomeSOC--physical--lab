# PowerShell Automation

This directory contains PowerShell scripts developed to automate Active Directory administration and IAM operations.

## Planned Scripts

| Script                            | Purpose                           |
| --------------------------------- | --------------------------------- |
| `create-users.ps1`                | Automate domain user provisioning |
| `create-organizational-units.ps1` | Create Active Directory OUs       |
| `audit-users.ps1`                 | Review and audit user accounts    |

## Skills Practiced

- PowerShell scripting
- Active Directory administration
- Bulk user provisioning
- Group management
- Identity auditing
- Administrative automation

All scripts will be tested in the isolated HomeSOC lab before being documented as completed.
